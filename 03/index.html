내가 좋아하는 것

친구들과 재미있게 놀기,
영상 만들기와 방송 활동,
음악 듣기, 맛있는 디저트 먹기, 새로운 경험 해보는 것을 좋아해요.

🎬

내가 잘하는 것

영상이나 방송처럼 여러 사람이 함께 만드는 일을 좋아하고, 아이디어를 생각하고 표현하는 것도 잘해요. 맡은 일은 은근 끝까지 해내는 스타일!

🔋

충전이 필요할 때

혼자 조용히 쉬거나 좋아하는 영상을 보고, 음악을 듣거나 친구들과 편하게 이야기하면 다시 에너지가 채워져요.

✨

나의 관심사

🎥 영상 · 방송 🎧 음악 💬 친구 📷 사진 🍰 맛있는 것 ✈️ 새로운 경험
⚠️

효정이를 대할 때 주의사항

기분이 좋지 않을 때 계속 캐묻기보다는 조금 기다려 주세요. 갑자기 짜증이 날 때도 있지만 혼자 생각할 시간이 조금 필요할 수 있어요. 이야기를 시작하면 일단 끝까지 들어주는 것이 중요합니다. 😊

효정이 사용 TIP

✔ 내 이야기를 먼저 잘 들어주세요.
✔ 같이 웃고 재미있는 일을 하면 빨리 친해져요.
✔ 하고 싶은 것을 스스로 선택할 시간을 주세요.
✔ 잘한 일은 구체적으로 칭찬해주면 효과 최고!
✔ 가끔은 혼자 있는 시간도 존중해주세요.
